KRA Automation System

                                                                    Welcome to KRA AUTOMATION SYSTEM Module

The KRA AUTOMATION SYSTEM Module deals with all the KRA related tasks and is one of the most important modules in the system.

KRA is nothing but the Variable Pay part of salary which is calculated at every Quarter that is based on employee's performance factors called as Value Drivers.This system can handle all KRA computation related activities automatically.

KRA(Key Result Area) is  based on Value Drivers and thier respective Weights and Computational Rule. These values are configurable and defaultly set by HR. According to which the Ratings are given to concern employee by Reporting Head at every reporting frequency (Monthly)  .

Computed KRA can be send to concern employee and HR person by E-mail for the further Total Salary process.

For more details click here : KRA Details

 
Guidelines for User :

 1. In the Whizible SEM application you will find all modules on the top menu.

Select Resources module and expnad KRA Automation System  node(as like fig.1) .

You will find two parent nodes as KRA Masters and Processing of KRA . 

KRA Masters can be filled up by the HR Manager for the default configurations.Processing of KRA  can be proccessed by Reporting Head for his/her Employees.                                  

Figure 1.  

2. Introduction to KRA : Gives you the introduction of KRA System and it is also available with the KRA Details  link which show how actually KRA for perticular employee is calculated.
3. Value Drivers :

     It will provide you th following screen to view the existing value drivers.You can view perticular value driver details by selecting its initial letter on the top left side.
Figure 2.
HR Manager can add new value driver by clicking Add action link.It show the following screen.It will allow HR to add value driver,its description,default ratings and Computational Rule.Rule can be selected from the Rule link next to Rule Textbox.Save this record by clicking Save link.
Figure 3.
3.Computation Rule :
In the following screen HR Manager can add new computation rule by clicking Add New Coputation Rule link.By default <0-100=100> rule immediately gets added into the Rules list.
This rule can be configured by clicking on it, it will open folloeing screen to configure new values.Save this record by clicking Save link.
4.Assign Role wise KRA :This screen used to assign default KRA Value Drivers Role wise.The weight can be configured in the summation of 100 for each value driver.The Balance weight in color Red indicates incorrect weight.Save settings by clicking Save.
HR can add new value drivers by clicking Add New Value Drivers.It will open Value Driver's Lookup page from which HR can select new Value Drivers by selecting and clicking Save Value Driver.

5.KRA Calculation Date : HR has to give this date , on this date SaveRating link must get click to get KRA calculated.
6.Initiate  KRA Process : HR can initiate the Quarter start  by clicking on Initiate link.
7. Employee KRA Configuration :This screen is used to configure Value drivers,weight and Computational rule for each employee by its Reporting Head.
8. KRA Rating :This screen is used give Rating to each employee,for each month (at the end) in the Quarter,by its Reporting Head. After rating employees as per the Reporting Head, data will get save.And for selected date, that selected by HR Team Member(in fig. ) KRA Calculation will be done. So user has to press Save Rating Link on that perticular date, to get the KRA calculated for that employee.
