Welcome to KRA AUTOMATION SYSTEM Module

The KRA AUTOMATION SYSTEM Module deals with all the KRA related tasks and is one of the most important modules in the system.

KRA is nothing but the Variable Pay part of salary which is calculated at every Quarter that is based on employee's performance factors called as Value Drivers.This system can handle all KRA computation related activities automatically.

 
                 

 

KRA(Key Result Area) is  based on Value Drivers and thier respective Weights and Computational Rule. These values are configurable and defaultly set by HR. According to which the Ratings are given to concern employee by Reporting Head at every reporting frequency (Monthly)  .

Computed KRA can be send to concern employee and HR person by E-mail for the further Total Salary process.
