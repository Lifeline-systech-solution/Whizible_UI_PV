3.KRA Rating Process:

    1. Assigning KRA rating for an employee:

Initially default rating values are set for each employee according to the role by HR member.(In case rating is not done by a concerned reporting head within set period, default value is applicable)


Reporting head must fill in rating against value drivers within specified days at the end of every month, otherwise default rating will be applied (say 50%).


User: Reporting Head.


    1. KRA Calculation:


Process Description:

  1. Rating will be given by concerned reporting head against each value driver to his team member.

  2. Rating is done progressively. (Say monthly, fortnightly)

  3. Computed value is calculated for each value driver based on KRA computation rule. (Refer table 3)

  4. Average of computed value is calculated.

  5. Sum of values in above step 4 will be considered to calculate total rating and variable pay.

Details about the computation of variable pay

Below example refers the data in above Table 4.

Assumption :

  • Yearly KRA amount is 4000 Rs.

  • So, Quarter wise KRA is 1000 Rs.

Calculation :

  • For first Value Driver “Project Performance”

Average Rating : 33.33 %

Weight : 40%

40 % of 1000 = 400 Rs.

33.33% of 400 = 133.32 Rs.


  • For Second Value Driver “Implementation”

40 % of 1000 = 400 Rs.

46.66% of 400 = 186.64 Rs.


  • For Third Value Driver “On time Completion”

10 % of 1000 = 100 Rs.

60% of 100 = 60 Rs.


  • For Fourth Value Driver “Team Management”

10 % of 1000 = 100 Rs.

33.33% of 100 = 33.33 Rs.


Finally the KRA for Quarter 1= 133.32 + 186.64 + 60 + 33.33 =413.29 Rs.

    4.Configurable Inputs :

  • KRA Rating Frequency Cycle (Say Monthly,Fortnightly)

  • Value Drivers and Respective Weights BU wise / Reporting Head wise

  • KRA Computation Rule


    5.Email notifications / Reminders:

  • Assigning KRA value drivers and respective weights to individual employee should be set within the 10 days (Configurable) of every month. In order to follow this process email reminder are set for specified days.

  • Email notification should be sent to the employee when reporting head generates KRA value drivers.

  • By the end of every month / quarter email reminder is set to fill-in the ratings by concerned reporting head. (Reminder day is set in the system and is configurable i.e. when reminder should be sent and for how many days it should pop up).

  • Email-notification is to be sent by the end of month/quarter to the employee and HR members once the computed KRA rating is assigned by his/her reporting head.
